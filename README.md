## What's inside

- **37 problems, all in C++** — arrays, strings, linked lists, dynamic programming, binary search, backtracking, sorting, hash tables and more.
- Every folder is named `<number>-<slug>` (e.g. `0001-two-sum`) and contains:
  - `<number>-<slug>.cpp` — the accepted solution as a LeetCode `Solution` class
  - `README.md` — the problem statement, examples and difficulty
- `stats.json` — LeetHub's sync record (per-problem file hashes and difficulty counts).

## How to use

- **Browse by topic** in the index below — it groups every problem under its LeetCode topics.
- **Read a solution:** open a problem folder, read its `README.md` for the statement, then the `.cpp` file for the solution.
- **Run a solution:** the `.cpp` files are LeetCode `Solution` classes, so they paste straight into the LeetCode editor. To run one locally, add a small `main()` driver and compile with `g++ -std=c++17 <file>.cpp -o solution`.

## How new solutions get added

The LeetHub v2 browser extension pushes each accepted submission here automatically, and refreshes the topic index below on every sync. Content between the `LeetCode Topics` markers is auto-generated — edit the sections around it, not inside it.
